# RetroAchievements fetched data

Generated by `scripts/fetch_retroachievements_data.py`. Do not edit by hand.

## Layout

- **consoles.json** – Full list of console ID/name (and other fields) from `API_GetConsoleIDs.php`.
- **games/<console_id>.json** – For each console, one file keyed by numeric console ID. Each file contains:
  - `consoleId` – same as the filename (e.g. `1`)
  - `consoleName` – display name (e.g. `"Mega Drive"`)
  - `games` – array of game objects from `API_GetGameList.php` with `i=<id>&h=1&f=1` (games with achievements, with hashes). Each game has e.g. `ID`, `Title`, `ConsoleID`, `ConsoleName`, `ImageIcon`, `NumAchievements`, `Points`, `Hashes`, etc.

## Using by console ID

To get all games for a given console ID (e.g. `5`), load:

```
data/retroachievements/games/5.json
```

Then use the `games` array and optionally `consoleName` from that object.
